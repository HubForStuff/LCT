# Vercel Blob Google Sheets Form Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Move the pre-registration form to a Vercel-backed custom submission flow that stores pitch decks and supporting files in private Vercel Blob storage, records submission metadata in Google Sheets, and supports deck-based AI form assistance.

**Architecture:** Keep the current Astro pages mostly static with `output: "hybrid"` and add Vercel serverless API routes only for upload tokens, form submission, private file download, and AI autofill. Files upload directly from the browser to a private Vercel Blob store so 20MB decks do not pass through Vercel Functions. Google Sheets is the v1 operational database: every valid submission appends one row containing all fields, private file download links, AI metadata, and a raw JSON backup.

**Tech Stack:** Astro 5, `@astrojs/vercel`, Vercel Blob, Google Sheets API via `googleapis`, `zod` for runtime validation, Node test runner, optional AI provider adapter.

## Chosen Data Flow

1. Browser loads `/pre-registration/`.
2. Browser creates a `submissionId` using `crypto.randomUUID()`.
3. User fills fields and selects files.
4. Browser uploads pitch deck and supporting files directly to Vercel Blob using `/api/blob/upload`.
5. Blob upload path uses the known `submissionId`:

```text
submissions/{submissionId}/deck/{safe-file-name}
submissions/{submissionId}/supporting/{index}-{safe-file-name}
```

6. Browser stores returned Blob metadata in memory.
7. If user clicks AI assistance:
   - Browser sends current form values plus pitch deck Blob metadata to `/api/ai/form-autofill`.
   - Server retrieves the private Blob.
   - Server extracts/analyzes deck content with the configured AI provider.
   - Browser fills empty fields and asks before overwriting non-empty fields.
8. On submit:
   - Browser verifies required fields and deck Blob metadata.
   - Browser sends JSON to `/api/submissions`.
   - Server validates payload with `zod`.
   - Server creates signed private download links for Blob files.
   - Server appends one row to Google Sheets.
   - Browser displays localized success or error UI.

## Security And Privacy Decisions

- Use a private Vercel Blob store.
- Never expose `BLOB_READ_WRITE_TOKEN`, Google credentials, or AI keys to the browser.
- Do not send raw files through `/api/submissions`; only send Blob metadata.
- Use `/api/files/download` to serve private Blobs.
- Download links in Google Sheets use an HMAC token generated with `FILE_DOWNLOAD_SECRET`.
- Treat anyone with the Google Sheet as authorized to access the files linked from rows.
- Do not log raw form payloads, deck text, or file contents.
- Add a honeypot field and origin check. Do not block legitimate users on weak client-only checks.
- Keep legal disclosure copy visible before AI use and submission.
- Add a privacy TODO for counsel review before production launch.

## Important Implementation Constraints

- Do not submit multipart form data to `/api/submissions`; Vercel Functions have payload limits and files must already be in Blob.
- The direct Blob upload route is public by necessity because applicants are unauthenticated. Constrain it tightly by content type, file size, path prefix, extension, and origin.
- Do not put download tokens in Blob metadata. Generate them server-side when appending to Sheets.
- Do not build an admin dashboard in this iteration. Google Sheets is the admin UI.
- Do not migrate all pages to server rendering. Use hybrid output and keep pages static unless an API route needs runtime.
- Do not rewrite the homepage.

```ts
import { createHmac, timingSafeEqual } from "node:crypto";
import { getFileDownloadEnv } from "./env";

function sign(value: string): string {
  const { secret } = getFileDownloadEnv();
  return createHmac("sha256", secret).update(value).digest("hex");
}

export function createBlobDownloadToken(pathname: string, expiresAt: number): string {
  return sign(`${pathname}:${expiresAt}`);
}

export function verifyBlobDownloadToken(pathname: string, expiresAt: number, token: string): boolean {
  if (Date.now() > expiresAt) {
    return false;
  }

  const expected = createBlobDownloadToken(pathname, expiresAt);
  const expectedBuffer = Buffer.from(expected);
  const tokenBuffer = Buffer.from(token);

  return expectedBuffer.length === tokenBuffer.length && timingSafeEqual(expectedBuffer, tokenBuffer);
}

export function createBlobDownloadUrl(requestUrl: string, pathname: string): string {
  const { ttlDays } = getFileDownloadEnv();
  const expiresAt = Date.now() + ttlDays * 24 * 60 * 60 * 1000;
  const token = createBlobDownloadToken(pathname, expiresAt);
  const url = new URL("/api/files/download", requestUrl);

  url.searchParams.set("pathname", pathname);
  url.searchParams.set("expires", String(expiresAt));
  url.searchParams.set("token", token);

  return url.toString();
}
```

```ts
import { get } from "@vercel/blob";
import { verifyBlobDownloadToken } from "../../../lib/server/blob-download-token";

export const prerender = false;

export async function GET({ request }: { request: Request }) {
  const url = new URL(request.url);
  const pathname = url.searchParams.get("pathname");
  const expires = Number(url.searchParams.get("expires"));
  const token = url.searchParams.get("token");

  if (!pathname || !expires || !token || !verifyBlobDownloadToken(pathname, expires, token)) {
    return new Response("Not found", { status: 404 });
  }

  const blob = await get(pathname);

  if (!blob) {
    return new Response("Not found", { status: 404 });
  }

  const response = await fetch(blob.url, {
    headers: process.env.BLOB_READ_WRITE_TOKEN
      ? { Authorization: `Bearer ${process.env.BLOB_READ_WRITE_TOKEN}` }
      : undefined,
  });

  if (!response.ok || !response.body) {
    return new Response("Not found", { status: 404 });
  }

  return new Response(response.body, {
    headers: {
      "Content-Type": response.headers.get("Content-Type") || "application/octet-stream",
      "Content-Disposition": `attachment; filename="${pathname.split("/").pop() || "file"}"`,
      "Cache-Control": "private, no-cache",
    },
  });
}
```

```ts
  deckFile: blobFileSchema,
});

export async function POST({ request }: { request: Request }) {
  if (process.env.PUBLIC_ENABLE_AI_ASSISTANCE !== "true") {
    return Response.json({ error: "AI Assistance is disabled." }, { status: 404 });
  }

  const parsed = requestSchema.safeParse(await request.json());

  if (!parsed.success) {
    return Response.json({ error: "Invalid AI request." }, { status: 400 });
  }

  try {
    const result = await generateFormAutofill({
      ...parsed.data,
      deck: parsed.data.deckFile,
    });

    return Response.json(result);
  } catch (error) {
    return Response.json(
      {
        error: error instanceof Error ? error.message : "AI Assistance failed.",
      },
      { status: 500 },
    );
  }
}
```
