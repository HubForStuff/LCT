# Events (Area H) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder `/events/` prose page with a data-driven events feature — a Keystatic-managed events collection, a filterable/sortable list page grouped by month, a detail page per event, and a dedicated event-application form that lands in Google Sheets.

**Architecture:** Follows the established data-driven page pattern (`competitions` is the canonical template): a Keystatic collection + `src/lib/events/{types,schema,reader,filters}.ts` feeding a list component and `/events/[slug]` detail routes. The events list deliberately reuses the competitions list's CSS classes (`ccard`, `comp-grid`, `filter-pill`, `tab`, `sort-select`) and its shell components, and reuses the competition filter-icon maps via a newly extracted shared module. It does **not** fork `CompetitionsPage.astro` — the events filter model (multi-select region with nested location panels, multi-select industry, month grouping) genuinely diverges and gets its own leaner component and script.

**Tech Stack:** Astro 5 (`output: "static"`), Keystatic (local storage), plain TypeScript readers, hand-inlined SVG icons, `node --test` build-and-assert tests, Google Apps Script form backend.

## The mockup is UI/UX guidance, not data — read before starting

**`mockup/5 - events_v11.htm` specifies how the page looks and behaves. Its 24 event cards are demo fixtures, not content.** Do not transcribe them into the collection as if they were real events, and do not encode anything about them into assertions.

What the mockup **is** authoritative for:

- Layout, spacing, card anatomy, badge treatments, filter-bar composition, month separators, tab bar, the placeholder tiles, the "More Events" affordance.
- The **filter vocabulary**: the four status options, the China city list, the LATAM country list grouped by sub-region, and the 16 industry pills. These are fixed taxonomies the CMS must offer, so they live in the locale JSON and are safe to assert against.
- The **field set** a card displays — which is what the collection schema must carry: code badge, date badge, status, category, name, description, location, and the Join / Book a Booth CTAs.

What the mockup is **not** authoritative for:

- **How many events exist.** The spec's "21 events (12 trade / 9 summit)" was read off the mockup's hardcoded `<span class="tab-count">12</span>` badges; counting actual `.ccard` elements gives 14 + 10 = 24. Both numbers are artifacts of a static design file. The real count is whatever the CMS holds. **Tab counts are derived from data at runtime and no test may assert a specific total.**
- **Which events exist.** Event names, dates, descriptions and cities in the mockup are invented. Task 2 ships a small **seed set** that exercises every UI state, clearly marked as replaceable, and Andre supplies the real calendar through Keystatic.
- **Industry assignments.** Only 5 of the 24 mockup cards carry `data-industry` at all. The taxonomy is real; the per-card values are not.

Two genuine UI defects in the mockup, to fix rather than reproduce:

1. **The China location filter cannot work.** Every China card carries `data-country="China"` while the dropdown offers city pills (Beijing, Shenzhen, …), so no card can ever match. In our model `location` carries the city: the China panel filters on `location`, the LATAM panel on `country`.
2. **Tab counts are hardcoded and already disagree with the markup** (badge says 9 summits; there are 10). Derive them, as `applyFilters()` in `CompetitionsPage.astro` already does.

> **Regression precedent.** `CHECKLIST.md` records a past incident where **production-visible test competitions** shipped and had to be draft-filtered. Seed events carry the same risk. Every seed entry gets a truthful `status` and stays subject to the `draft` flag, and Task 7 raises the "replace seed content" item explicitly.

// src/lib/events/filters.mjs
/**
 * Pure filter/sort/group helpers for the events listing.
 * Framework-agnostic and dependency-free so they can be unit-tested directly
 * and imported by both the Astro component (build time) and its client script.
 */

const MONTH_NAMES = {
  EN: ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"],
  BR: ["Janeiro", "Fevereiro", "Março", "Abril", "Maio", "Junho", "Julho", "Agosto", "Setembro", "Outubro", "Novembro", "Dezembro"],
};

const STATUS_RANK = { open: 0, upcoming: 1, past: 2 };

/** @param {string} isoDate @returns {string} */
export function monthKey(isoDate) {
  return isoDate.slice(0, 7);
}

/** @param {string} isoDate @param {"EN"|"BR"|"CN"} locale @returns {string} */
export function monthLabel(isoDate, locale) {
  const year = isoDate.slice(0, 4);
  const monthIndex = Number(isoDate.slice(5, 7)) - 1;

  if (locale === "CN") {
    return `${year}年${monthIndex + 1}月`;
  }

  const names = MONTH_NAMES[locale] || MONTH_NAMES.EN;
  return `${names[monthIndex]} ${year}`;
}

/**
 * @param {{startDate: string}[]} cards
 * @param {"EN"|"BR"|"CN"} locale
 * @returns {{key: string, label: string, cards: any[]}[]}
 */
export function groupByMonth(cards, locale) {
  const buckets = new Map();

  for (const card of cards) {
    const key = monthKey(card.startDate);
    if (!buckets.has(key)) {
      buckets.set(key, { key, label: monthLabel(card.startDate, locale), cards: [] });
    }
    buckets.get(key).cards.push(card);
  }

  return [...buckets.values()].sort((left, right) => left.key.localeCompare(right.key));
}

/** @param {any[]} cards @returns {any[]} */
export function sortByDate(cards) {
  return [...cards].sort((left, right) => {
    const rankDifference = (STATUS_RANK[left.status] ?? 3) - (STATUS_RANK[right.status] ?? 3);
    if (rankDifference) {
      return rankDifference;
    }

    const dateDifference = left.startDate.localeCompare(right.startDate);
    if (dateDifference) {
      return dateDifference;
    }

    return (left.order ?? 0) - (right.order ?? 0);
  });
}

/** @param {any[]} cards @returns {any[]} */
export function sortByRegion(cards) {
  return [...cards].sort((left, right) => {
    const regionDifference = left.region.localeCompare(right.region);
    if (regionDifference) {
      return regionDifference;
    }

    const locationDifference = left.location.localeCompare(right.location);
    if (locationDifference) {
      return locationDifference;
    }

    return left.startDate.localeCompare(right.startDate);
  });
}

/**
 * @param {any} card
 * @param {{status: string, region: string, latamCountries: string[], chinaLocations: string[], industries: string[]}} state
 * @returns {boolean}
 */
export function matchesFilters(card, state) {
  const matchesStatus = state.status === "all" || card.status === state.status;

  let matchesRegion;
  if (state.region === "all") {
    matchesRegion = true;
  } else if (state.region === "latam") {
    matchesRegion =
      card.region === "latam" &&
      (state.latamCountries.length === 0 || state.latamCountries.includes(card.country));
  } else {
    matchesRegion =
      card.region === "china" &&
      (state.chinaLocations.length === 0 || state.chinaLocations.includes(card.location));
  }

  const matchesIndustry =
    state.industries.length === 0 || state.industries.includes(card.industry);

  return matchesStatus && matchesRegion && matchesIndustry;
}

```astro
<script>
  import { matchesFilters, sortByDate, sortByRegion } from "../../lib/events/filters.mjs";

  const tabTriggers = Array.from(document.querySelectorAll("[data-tab-trigger]"));
  const tabPanels = Array.from(document.querySelectorAll("[data-tab-panel]"));
  const statusButtons = Array.from(document.querySelectorAll("[data-status-filter]"));
  const regionButtons = Array.from(document.querySelectorAll("[data-region-filter]"));
  const industryButtons = Array.from(document.querySelectorAll("[data-industry-filter]"));
  const chinaButtons = Array.from(document.querySelectorAll("[data-china-location]"));
  const latamButtons = Array.from(document.querySelectorAll("[data-latam-country]"));
  const sortSelect = document.getElementById("eventSort");

  const state = {
    status: "all",
    region: "all",
    latamCountries: [],
    chinaLocations: [],
    industries: [],
  };

  function cardModel(node) {
    return {
      status: node.dataset.status,
      region: node.dataset.region,
      country: node.dataset.country,
      location: node.dataset.location,
      industry: node.dataset.industry,
      startDate: node.dataset.startDate,
      order: Number(node.dataset.order) || 0,
      node,
    };
  }

  function applyFilters() {
    document.querySelectorAll("[data-event-card]").forEach((node) => {
      node.hidden = !matchesFilters(cardModel(node), state);
    });

    // Hide a month separator when every card under it is filtered out — an orphan
    // month heading reads as a rendering bug.
    document.querySelectorAll("[data-month-grid]").forEach((grid) => {
      const key = grid.dataset.monthGrid;
      const separator = document.querySelector(`[data-month-group="${key}"]`);
      const anyVisible = Array.from(grid.querySelectorAll("[data-event-card]")).some((c) => !c.hidden);
      grid.hidden = !anyVisible;
      if (separator) separator.hidden = !anyVisible;
    });

    // Tab counts are always derived from what is visible, never hardcoded.
    tabTriggers.forEach((trigger) => {
      const panel = document.querySelector(`[data-tab-panel="${trigger.dataset.tabTrigger}"]`);
      const countNode = trigger.querySelector(".tab-count");
      if (!panel || !countNode) return;
      countNode.textContent = String(
        Array.from(panel.querySelectorAll("[data-event-card]")).filter((c) => !c.hidden).length,
      );
    });
  }

  function toggleInArray(list, value) {
    const index = list.indexOf(value);
    if (index === -1) list.push(value);
    else list.splice(index, 1);
  }

  function syncPressed(buttons, isActive) {
    buttons.forEach((button) => button.classList.toggle("is-active", isActive(button)));
  }

  function activateTab(tabId) {
    tabTriggers.forEach((trigger) => {
      const isActive = trigger.dataset.tabTrigger === tabId;
      trigger.classList.toggle("is-active", isActive);
      trigger.setAttribute("aria-selected", isActive ? "true" : "false");
    });
    tabPanels.forEach((panel) => {
      const isActive = panel.dataset.tabPanel === tabId;
      panel.classList.toggle("is-active", isActive);
      panel.hidden = !isActive;
    });
  }

  function sortCards() {
    const useRegion = sortSelect instanceof HTMLSelectElement && sortSelect.selectedIndex === 1;
    document.querySelectorAll("[data-month-grid]").forEach((grid) => {
      const cards = Array.from(grid.querySelectorAll("[data-event-card]")).map(cardModel);
      const sorted = useRegion ? sortByRegion(cards) : sortByDate(cards);
      const extras = Array.from(grid.children).filter((child) => !child.hasAttribute("data-event-card"));
      grid.replaceChildren(...sorted.map((c) => c.node), ...extras);
    });
  }

  statusButtons.forEach((button) =>
    button.addEventListener("click", () => {
      state.status = button.dataset.statusFilter;
      syncPressed(statusButtons, (b) => b.dataset.statusFilter === state.status);
      applyFilters();
    }),
  );

  regionButtons.forEach((button) =>
    button.addEventListener("click", () => {
      const value = button.dataset.regionFilter;
      if (value === "all") {
        state.region = "all";
        state.latamCountries.length = 0;
        state.chinaLocations.length = 0;
        syncPressed(chinaButtons, () => false);
        syncPressed(latamButtons, () => false);
      } else {
        state.region = value;
      }
      syncPressed(regionButtons, (b) => b.dataset.regionFilter === state.region);
      applyFilters();
    }),
  );

  chinaButtons.forEach((button) =>
    button.addEventListener("click", (event) => {
      event.stopPropagation();
      toggleInArray(state.chinaLocations, button.dataset.chinaLocation);
      state.latamCountries.length = 0;
      syncPressed(latamButtons, () => false);
      state.region = state.chinaLocations.length > 0 ? "china" : state.region;
      syncPressed(chinaButtons, (b) => state.chinaLocations.includes(b.dataset.chinaLocation));
      syncPressed(regionButtons, (b) => b.dataset.regionFilter === state.region);
      applyFilters();
    }),
  );

  latamButtons.forEach((button) =>
    button.addEventListener("click", (event) => {
      event.stopPropagation();
      toggleInArray(state.latamCountries, button.dataset.latamCountry);
      state.chinaLocations.length = 0;
      syncPressed(chinaButtons, () => false);
      state.region = state.latamCountries.length > 0 ? "latam" : state.region;
      syncPressed(latamButtons, (b) => state.latamCountries.includes(b.dataset.latamCountry));
      syncPressed(regionButtons, (b) => b.dataset.regionFilter === state.region);
      applyFilters();
    }),
  );

  industryButtons.forEach((button) =>
    button.addEventListener("click", () => {
      const value = button.dataset.industryFilter;
      if (value === "all") state.industries.length = 0;
      else toggleInArray(state.industries, value);
      syncPressed(industryButtons, (b) =>
        b.dataset.industryFilter === "all"
          ? state.industries.length === 0
          : state.industries.includes(b.dataset.industryFilter),
      );
      applyFilters();
    }),
  );

  document.querySelectorAll("[data-region-trigger]").forEach((trigger) =>
    trigger.addEventListener("click", (event) => {
      event.stopPropagation();
      const name = trigger.dataset.regionTrigger;
      document.querySelectorAll("[data-region-wrap]").forEach((wrap) => {
        wrap.classList.toggle("open", wrap.dataset.regionWrap === name && !wrap.classList.contains("open"));
      });
    }),
  );

  document.addEventListener("click", (event) => {
    document.querySelectorAll("[data-region-wrap]").forEach((wrap) => {
      if (!wrap.contains(event.target)) wrap.classList.remove("open");
    });
  });

  tabTriggers.forEach((trigger) =>
    trigger.addEventListener("click", () => {
      activateTab(trigger.dataset.tabTrigger);
      sortCards();
    }),
  );

  if (sortSelect instanceof HTMLSelectElement) {
    sortSelect.addEventListener("change", sortCards);
  }

  applyFilters();
  sortCards();

  // Deep links: ?tab=summit, and the mega-menu hashes /events/#trade-fairs-expos and #summits.
  const tabParam = new URLSearchParams(window.location.search).get("tab");
  const hash = window.location.hash.replace("#", "");
  const hashTab = tabPanels.find((panel) => panel.id === hash);
  const target = tabParam || (hashTab ? hashTab.dataset.tabPanel : "");
  if (target && tabTriggers.some((t) => t.dataset.tabTrigger === target)) {
    activateTab(target);
    applyFilters();
    sortCards();
  }
</script>

/**
 * Pure, framework-agnostic submit adapter for the event application form.
 * Sends multipart FormData (a CORS-safe-listed content type → no preflight), so the
 * Apps Script Web App's 302→googleusercontent redirect is followed and the JSON
 * response is readable. Do NOT set Content-Type: the browser must add the multipart boundary.
 * The FormData must carry formType=event-application so Code.gs routes it to the
 * Event Applications sheet.
 *
 * @param {string} endpoint  Apps Script /exec URL
 * @param {FormData} formData
 * @param {typeof fetch} [fetchImpl]
 * @returns {Promise<{ ok: boolean, error?: string }>}
 */
export async function submitEventApplication(endpoint, formData, fetchImpl = globalThis.fetch) {
  try {
    const response = await fetchImpl(endpoint, { method: "POST", body: formData });
    const data = await response.json().catch(() => ({}));
    if (response.ok && data && data.ok) return { ok: true };
    return { ok: false, error: (data && data.error) || `Request failed (${response.status})` };
  } catch (error) {
    return { ok: false, error: error && error.message ? error.message : "Network error" };
  }
}
```
