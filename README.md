# Inovação Hub 🚀

Website de hub de inovação construído com Astro e Keystatic.

## Tecnologias

- **Astro** - Framework web moderno
- **Keystatic** - CMS baseado em Git
- **Tailwind CSS** - Estilização utilitária
- **TypeScript** - Tipagem estática

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## Deploy

O site é automaticamente deployado para GitHub Pages via GitHub Actions quando há push para a branch `main`.

## Estrutura

- `/src/pages` - Páginas do site
- `/src/components` - Componentes reutilizáveis
- `/src/layouts` - Layouts de página
- `/src/content` - Coleções de conteúdo
- `/public` - Arquivos estáticos
